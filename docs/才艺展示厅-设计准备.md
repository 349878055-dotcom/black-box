# 才艺展示厅 · 设计准备（个人助理5）

> 从工作台 4.0 迁入的**可交互模拟原型**，供你改 UI、定架构。  
> 铁律：**用户只面对人**；skill 挂在人下面。  
> **客户侧不实名**：逛、搜、找人办事都不拦；实名只可能是上台的人（工作台侧），不进客户 App。

## 客户怎么走

1. 顶栏 ✨ → 找人办事  
2. 搜「挂号 / 买票 / 外卖」或点分类  
3. 点人 → 看「能帮你办的事」（技能）和做事习惯  
4. 「找 TA 办事」→ 回到虾米对话，才艺只在此人名下激活  

客户不填身份证、不看证件号、不进「幕后」。评价：找过 TA 之后才能写。

## 在哪

| 路径 | 用途 |
| --- | --- |
| `app/app/src/main/assets/showcase/index.html` | 虾米 App 内展示厅页面 |
| `app/app/src/main/assets/ui.html` | 主壳：顶栏 ✨、对话列表底栏「才艺展示厅」 |

## 怎么打开

虾米 App 内：顶栏 ✨，或对话列表底栏「才艺展示厅」。改完后需重新安装 APK 才能在手机上看到。

## 模拟里有什么

- **找人办事**：搜事、分类（挂号/出行/外卖）、综合/本周/好评（排的是人）
- **个人页**：评分、完成单、能办的事（技能）、做事习惯、评价
- **找 TA 办事**：跳回虾米对话，展示厅里不再单独开聊天
- 客户不实名、不看证件、不进幕后

## 和 App 怎么接（已预埋）

1. 展示厅 iframe 加载 `showcase/index.html`
2. 用户点「找 TA 办事」→ `postMessage({ type:'showcase:hire', personId, ... })`
3. `ui.html` 的 `startPersonChatFromShowcase` 创建会话，`persona` 写入：

```json
{
  "person_id": "zhou",
  "person_name": "周姐",
  "skills": ["glyy", "tuniu", "meituan_waimai"],
  "source": "showcase"
}
```

4. **下一步你要设计的**：云端 agent 读 `persona.person_id`，只加载此人 `skills[]`，未选人拒绝 `skill_run`。

## 数据改哪

模拟人物数据在 `index.html` 内 `const PEOPLE = [...]`。  
设计阶段可拆成 `people.json`，用 `fetch('people.json')` 加载，方便只改 JSON 不动页面。

## 与工作台 4.0 的分工

| 端 | 职责 |
| --- | --- |
| **工作台 4.0** | 产 `skills/{id}/`，过门禁 |
| **个人助理5** | 消费 skill；展示厅只展示**人**；人挂 skill + 经验 |
