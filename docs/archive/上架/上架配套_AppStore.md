# 上架配套（Device-as-Proxy 第 8 条）· App Store Connect 材料

> 目标：App 能过 App Store / Google Play 审核。
> 红线对照（Device-as-Proxy 上架约束，全表见文末 §5 技术合规自检）：
> **A 远程代码 / B 内购抽成 / C 爬虫壳 / D 隐私聚合 / E 误导隐藏。**

## 1. 产品定位（审核文案，红线 C/E）

- **App 名称**：虾米 · AI 生活助手
- **一句话简介**：AI 帮你对话、查资讯、管理日常事务的个人生活助手。
- **功能描述（对外口径）**：语音/文字对话、联网资讯、日程提醒、网页浏览配合。
- **禁止出现字样**：逆向 / 抓包 / 自动抢票 / 刷票 / 爬虫 / 破解 / 绕过风控 / 模拟点击。
  - 仓库代码中已改为中性表述（见 `MainActivity.java` 注释）。
  - 上线前用 `grep -r "逆向\|抓包\|抢票\|破解\|爬虫" app/` 自检，必须零命中。
- **不做审核版/正式版两套逻辑**（红线 E）：功能一致，仅云端配置灰度开关。

## 2. Privacy Manifest / 数据安全声明（红线 D）

### Android（Google Play「Data safety」表单）
| 声明项 | 填写 |
|---|---|
| 收集的数据 | 用户账号（第三方平台登录态，仅存本机）、对话文本、设备标识（用于登录） |
| 数据用途 | App 功能 / 账号管理 |
| 数据是否分享 | 否（第三方平台登录态只存用户手机本地，云端不聚合） |
| 数据删除 | 提供「清除本地凭据」入口（`CredentialStore` 数据随卸载清除） |

### iOS（Privacy Manifest `PrivacyInfo.xcprivacy` 要点）
- `NSPrivacyAccessedAPITypeUserDefaults`：凭据库（SharedPreferences 对应）——记录用途为「仅用户设备内存储用户自己的第三方账号凭据」。
- `NSPrivacyCollectedDataTypes`：`Name` / `PhoneNumber` / `UserID` / `SearchHistory`——用途均为「仅 App 功能，用户主动输入」，不关联第三方追踪。
- 说明文案：**“App 仅在你授权后，使用你自己的第三方账号访问对应服务；凭据只保存在你的设备上，云端服务器不收集、不保存你的第三方账号密码。”**

## 3. 审核演示（红线 C/E，走无害功能）

审核演示账号只走**无害功能**，敏感功能需用户授权触发：

| 场景 | 演示内容 | 是否触碰红线 |
|---|---|---|
| 对话 | 天气查询 / 通用问答 / 资讯检索（`web_search`） | 否 |
| Skill 市场 | 浏览已上架 skill 列表 | 否 |
| 登录 | 本 App 账号登录（非第三方） | 否 |
| 敏感功能 | 平台业务（挂号/购票）——需用户**显式授权** + 真人验证码配合 | 是，仅演示不触发 |
