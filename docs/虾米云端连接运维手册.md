## 三、为什么「总连不上」——全部根因与解法

### 根因 ①（最常见）虾米 App 未登录 / 登录态丢失
- **现象**：凭据库空（`/data/data/com.xiami.host/shared_prefs/xiami_creds.xml` 里 token/refresh 全空）、localStorage 空 → `connectWS()` 因 `!S.token || !S.deviceId` 直接 return，**根本不发起 WS** → 云端永远「手机未在线」。
- **触发**：清 App 数据 / 重装 / token+refresh 双双失效（日志见 `auth/refresh 401`）。
- **解法**：手机打开虾米 App → 点顶部「未登录」→ 输入邮箱+密码登录一次。登录成功即自动连 WS。
  - ⚠️ 云端 **无 API 能代填手机 WebView 的登录表单**（`/api/v1/dev/browser` 只驱动内置浏览器，不驱动虾米主界面）。**登录必须真人在手机上输一次**。

### 根因 ② xiami_base 缓存了旧地址（连错服务器）
- **现象**：App 优先读 `localStorage['xiami_base']`（[`ui.html:586`](/home/jintao/桌面/个人助理5/app/app/src/main/assets/ui.html:586)），若曾存过局域网/旧 IP，就永远连错地方，且设置页已移除（[`ui.html:1040`](/home/jintao/桌面/个人助理5/app/app/src/main/assets/ui.html:1040)），App 内改不了。
- **解法**：清虾米 App 数据/重装 → base 回默认 `http://140.143.144.28` → 重新登录。

### 根因 ③ 断线后无法自动重连
- **现象**：`ws.onclose` 只 `setTimeout(connectWS, 3000)` 重连，但若 token 已失效（refresh 也 401），重连永远失败；若 App 进程被系统杀（后台进程限制），WS 直接没了。
- **解法**：
  - 后台进程限制必须为 `-1`（不限）：`adb shell settings put global background_process_limit -1`
  - 保持虾米在前台/后台存活，别用「一键清理」杀它。

### 根因 ④ 云端服务/nginx 异常（已排除）
- **现状**（2026-08-11 实测）：health OK、systemd running、`:80`→nginx→`:19000` WS 代理正常、公网可访问（手机 ping `140.143.144.28` 通，50% 丢包属腾讯云 ICMP 限流，不影响 TCP/HTTP/WS）。
- **若真要查**：`systemctl status shimeban-cloud`、`curl -s http://127.0.0.1:19000/health`、nginx 配置见 `/etc/nginx/sites-available/shimeban-cloud`（已含 `Upgrade`/`Connection` 头）。

## 四、5 分钟排查流程（照着走）

```bash
# ① 云端服务活着吗

grep "349878055" /home/ubuntu/xiami/cloud/service.log | tail
# 期望看到最近一条 [bridge] 设备执行通道上线 device=...349878055... 在线=1
# 若只有「下线」或根本没有 → 手机端未登录/没连（去根因①/②/③）

# ③ 手机能不能到云端
adb shell ping -c 2 140.143.144.28    # 通即可（丢包=ICMP限流，非断连）

# ④ 手机端登录态
adb shell "run-as com.xiami.host cat /data/data/com.xiami.host/shared_prefs/xiami_creds.xml"
# token_..._glyy / refresh_... 非空 = 登录过；全空 = 需重新登录
```

**恢复动作清单**（按需执行）：
1. 手机打开虾米 → 登录（根因①）
2. 若 base 旧：清虾米数据/重装 → 重登（根因②）
3. `adb shell settings put global background_process_limit -1`（根因③）
4. 登完看云端日志出现 `在线=1`，再发一个 skill_run 确认能走手机通道。

## 六、易错点 & 防再犯清单

1. **登录是唯一手动步骤**：云端/脚本无法代填虾米 WebView 登录框；不要尝试模拟点击（不可靠）。
2. **别杀虾米后台**：Android 后台进程限制要 `-1`；系统「一键清理」会断 WS。
3. **登录态会失效**：refresh 401 后必须重登；清数据/重装也会清登录态（属正常，不是故障）。
4. **手机 ping 丢包是假象**：腾讯云 ICMP 限流，50% 丢包≠断网，TCP/WS 正常。
5. **改配置后看日志**：`/home/ubuntu/xiami/cloud/service.log` 是唯一事实来源（bridge 上线/下线、registry 拦截）。
6. **设备键 = 邮箱**：`device_id=349878055@qq.com`，与虾米账号邮箱严格一致，别改。
