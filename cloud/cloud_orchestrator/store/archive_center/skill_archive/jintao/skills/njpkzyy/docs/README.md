# 浦口中医院（路径 B：查号源 + 拉起支付宝）

> 不代登录、不代挂号、不代支付。微信小程序只探路。

## 三问（已定死）

| 问 | 答 |
|---|---|
| 探路用什么 | 微信缓存挖去缓存的 API；公开查询能打 |
| 登录态有什么 | **放弃**。登录在支付宝里，我们拿不到微信授权 |
| 交付是什么 | `alipays://` 拉起支付宝，进挂号确认页 |

## 客户动作

查科室/医生/排班 → 生成支付宝 scheme → 点一下 → 支付宝弹出确认页 → 客户自己登录、确认、付钱。

微信卡包 / URL Link / JSAPI 不交。禁止只给医院首页。
