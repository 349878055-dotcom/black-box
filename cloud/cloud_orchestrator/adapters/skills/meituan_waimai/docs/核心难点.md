# 美团外卖 Skill · 核心难点（最简版）

## 一句话现状
**看店/菜单/加购/结算预览已通**；**下单 submit 被拦**；**支付必须真微信**。

## 核心难点（3 个）

### 1️⃣ 下单 submit 403（最关键）
- 接口：`i.waimai.meituan.com/openh5/order/v2/submit`
- 根因：**mtgsig 风控签名**（绑定浏览器指纹/IP），虾米 WebView 算不出有效签名 → 403
- 打通路：**weapp 通道（真微信）** `wx.waimai.meituan.com/weapp/v6/order/submit` 已验证能下单（海外 IP 也行）；或 **unidbg** 服务端生成 mtgsig 直连 API

### 2️⃣ 支付 JSAPI（必须真微信）
- 支付 = `wx.requestPayment`（微信小程序原生 JSAPI），**虾米 WebView 触发不了**
- 方案：**API 生成订单链接 → 返回客户 → 客户微信/Safari 打开 → 确认订单 + 支付**（客户唯一动作）

### 3️⃣ 登录态三通道不互通
- **H5 cookie**（openh5）：已通，看店/菜单/加购/结算
- **微信小程序态**（weapp）：真微信，下单/支付
- **App token**（App API）：真机登录+抓通信，走 mtgsig 直连
- 别混用；App 版 token 靠真机登录+抓包获取

## 环境坑（快速避雷）
| 坑 | 解法 |
|---|---|
| 默认 UA 进店菜单"出现点问题" | 用**微信 UA** |
| onPageStarted 注入 JS 破坏美团 H5 | **用 eval 按需注入** mock 定位 |
| JS 模拟点击对按钮无效 | 需**真实触摸**（用户手动） |
| 清缓存破坏美团 | 只清购物车/订单，**别删 dfp** |
| 海外手机拿不到国内定位 | 注入 mock 定位（南京雨山美地） |

## 接口速查
- ✅ 200：`getuserorders`（查单）、`openh5/order/v2/preview`（结算）、`weapp/v6/order/submit`（下单）、`weapp/v1/payment/pay`（支付参数）
- ❌ 403：`wxapp/v2/search/*`（搜店）、`openh5/order/v2/submit`（下单）
- ⚠️ 9999：`wxapp/v2/poi/homepage`（首页）
- 🔗 域名：`h5.waimai`（页面）、`i.waimai`（openh5 API）、`wx.waimai`（weapp）、`wx-shangou`（wxapp）、`web.meituan`（无效404）
