# 途牛 Skill

买火车票：查车次 → 下单 → 支付（拉起支付宝）→ 查订单 → 退票。

## 功能
- 查车次/机票/酒店/门票（MCP 免费）
- 下单买火车票（乘客直传，免网页加乘客）
- 支付：自动拉起支付宝 App
- 查订单 / 退票（未支付可退）

## 接口来源
- 查询：途牛**开放平台 MCP**（JSON-RPC + SSE，apiKey 请求头）
- 下单/支付/订单/退票：途牛 **M 网页**（m.tuniu.com / api.tuniu.com，HTTP JSON/表单，cookie 登录态）

## ⚠️ 重要事项
- **已出票订单不能自助退票**（途牛限制）→ 需途牛客服 400-797-6666 / 火车站窗口
- 下单是真实购票会扣钱，下单前确认
- 未支付/占座中的订单可自动退

## 登录态说明（核心难点）
- 登录需**真人配合**：手机号 + 短信验证码 + **腾讯滑块**（滑块必现不可跳过，只能真人网页拖）；
- 登录态 = cookie，存手机授权中心（云端不持有），换窗口/重启自动复用；
- 未登录时下单 → 自动弹内置浏览器登录页 → 登录后自动导 cookie 继续。

## 支付机制（怎么弄出来的）
- 下单成功 → 内置浏览器打开途牛收银台 → 点「支付宝」→ 途牛返回 `alipays://` → App 拉起支付宝 App → 你付款；
- 我们不是支付宝商户，支付 =「途牛生成拉起协议，App 负责拉起支付宝」，付款在支付宝内完成。

## 核心难点 / 坑（给维护者看）
1. **已出票不能自助退票**（转客服 400-797-6666 / 火车站窗口）；
2. 支付接口偶发超时（网络波动，重试即可）；
3. 便捷购票 +¥10/张服务费；
4. 实名制：乘客姓名/身份证/手机必须真实，不能乱填。

## 使用流程（老百姓视角）
登录（一次）→ 问（说要买什么）→ 查（车次/票价）→ 填（乘客信息）→ 提交（下单 + 支付拉起支付宝）→ 出票乘车。

## 使用要求
- 手机 App 在线
- 信息齐全：车次/日期/席别/乘客（姓名+身份证+手机）
