# 鼓楼医院 Skill

挂号：查科室/医生/排班 → 挂号 → 查订单/取消。

## 功能
- 查科室/医生/排班/可约日期（公开）
- 挂号（一键挂号）
- 我的就诊 / 病历 / 缴费 / 取消预约

## 接口来源
- **微信小程序抓包**（appid wx74a991a2ae77468d）+ 小程序代码逆向
- HTTP JSON；sign=SHA1(MD5(appKey+ts+nonce))；Bearer token 登录态

## ⚠️ 重要事项
- **挂号是真实操作会占号**，提交前确认
- 登录态 token 存手机授权中心（手机号 + 短信登录，图形验证码真人配合）

## 登录态说明（核心难点）
- 登录需**真人配合**：图形验证码 + 短信验证码；
- 登录态 = Bearer token + refresh_token，存手机授权中心；token 快过期自动用 refresh_token 静默续期。

## 核心难点 / 坑（给维护者看）
1. 挂号是真实操作会占号，提交前确认；
2. 图形验证码需真人看图（模型禁图，只能 App 显示给用户）；
3. 接口需微信 UA + sign 签名（SHA1(MD5(appKey+ts+nonce))），错一个就失败。

## 使用流程（老百姓视角）
登录（一次）→ 问（要看哪个科/医生）→ 查（科室/排班）→ 填（患者信息）→ 提交（挂号）→ 就诊/查报告。

## 使用要求
- 手机 App 在线
- 患者信息齐全（姓名/身份证/手机）
