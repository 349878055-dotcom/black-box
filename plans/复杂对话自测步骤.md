## 4. 判定标准

**PASS**：
- 全程 ask_user 一次一问，无「done/纯文本带文字反问」收尾；
- 已给信息不重复问（form / 上下文接住）；
- 打断/改主意被处理，不重复原 ask、不卡死；
- 咨询/闲聊不误伤。

**FAIL（记录下来）**：
- 出现 done 或纯文本带「请告诉我…/请问…」文字反问；
- 反复问同一已给字段（form 没接住 → 查 form.json / load_contract_parts）；
- 打断后 bot 重复原 ask 或任务卡住（busy 吞 → 查 routes.py 打断喂回）；
- 「死机」：服务被 kill / 手机收不到回复（查下方日志）。

## 6. 出问题怎么查

| 症状 | 工具/动作 |
|---|---|
| 看云端日志 | `python3 tools/_check_cloud_log.py`（或 ssh 查 journalctl） |
| 服务是否被 kill/死机 | `systemctl status shimeban-cloud.service`；journalctl 里搜 `status=9/KILL` |
| 看模型本地真实轨迹（调了什么工具） | 云端日志 / `tools/selftest_gate_scenarios.py` |
| 打断喂回不生效 | 确认 `cloud/cloud_orchestrator/api/routes.py` 已部署（无 ask_id 走 feed_answer 唯一等待） |
| form 没生效（反复问） | 确认 skill 有 `contract/form.json`，且 `load_contract_parts` 读 form（skill_archive/__init__.py） |
