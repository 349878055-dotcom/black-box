### 3. 已摸清的 12320 接口（requests 直调，`skill_maker/nj12320_api.py`）
| 功能 | 接口 | 说明 |
|---|---|---|
| 登录检测 | `POST /njres/indexJson/getUserName.do` | null=未登录 / 用户名=已登录 |
| 医院搜索 | `GET /njres/reservation/hos_search.do?hosname=X` | HTML 解析 hoscode |
| 科室列表 | `GET /njres/reservation/hos_showReservation.do?hoscode=X` | HTML 解析 depid |
| 排班 | `GET /njres/reservation/dep_detail.do?depid=X&hoscode=X` | HTML 解析 toShowSchedule('hos',schcode,'am'/'pm') + title(日期/挂号费) |
| 时段 | `POST /njres/reservationJson/showScheduleTime.do` 参数 `hoscode/type(am\|pm)/schcode` | JSON `[{code,endHour,startHour,state,takeTime}]`，state=1 可约；**双层 JSON 字符串需解析两次**；需要 JSESSIONID（自动初始化） |
| 预约规则 | `POST /njres/reservationJson/checkResRule.do?schcode=X` | 返回 `noLogin`/`noPhone`/`success` |
| 预约登录 | `POST /njres/indexJson/login.do`（+ `GET /njmine/authImg.do` 验证码图） | 需图形验证码真人 |

**关键**：12320 有两套登录——用户中心 `/njmine/showLoginUI.do` 和 **预约系统 `/njres/index_toLogin.do`**；预约提交（checkResRule）检测**预约系统登录**，跨会话 cookie 不可靠（session 短、多端口/多路径），**建议同一会话内登录+预约**。
